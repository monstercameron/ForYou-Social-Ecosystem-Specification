# Synthetic examples

All keys, fee amounts and balances in this directory are public synthetic test data. The examples name Bitcoin mainnet only to exercise schema shape; no funds or real account are involved. The example schedule is not fee schedule 1 and carries no release approval. These examples do not constitute an activated fee schedule, proof of funding or debit, a live offer or a deployment configuration. Never send funds based on these fixtures.

- `fee-schedule.example.json` illustrates the shape of a schedule using deliberately fictitious values.
- `post-comment-thread.json` contains three signed posts linked by `reply_to`.
- `post-version-chain.json` contains an original, two versions, a competing fork and a reply to the original.
- `post-with-media-slots.json` contains one Markdown image-slot reference and one video slot, both external URLs on an example domain.
- `settlement.example.json` contains a synthetic genesis manifest (release keys, Foundation key certificate, fee schedule 1 for both networks with release approvals, distribution policy 1), retention declarations, a settlement claim with its leaves, committee witnesses and a settlement proof, a refusal, a vault receipt, a quarterly distribution statement and a key succession. It is generated by `python tests/economics_model.py --write` and checked by `tests/test_economics_v1.py`.
- `post-with-refs.json` demonstrates a signed DID mention, a post reference and an undeclared reference that remains inert.
- `name-record.example.json` contains a signed display name record of the optional display names profile and a later withdrawal record that replaces it. It is generated by `python tests/test_display_names.py --write` and checked by the same file. A signed name proves only which key signed it.

The media-slot digests use the exact UTF-8 test byte strings `ForYou example image object bytes\n` and `ForYou example video object bytes\n` respectively, where `\n` represents a single line-feed byte. These are synthetic hash vectors, not valid image/video files or claims about the contents of the example URLs. Nothing was downloaded; a client would reject bytes whose digest does not match.

Each record includes a synthetic provider-signed quote and receipt. The signatures and content IDs demonstrate byte bindings only; they do not establish that a balance existed or a real debit occurred. The real amounts are in the economics specification.
